# Build guides and assembly notes

Step-by-step build guides for the printed and sheet metal builds are not yet available. Use [Monolith Builder](https://build.monolith3d.xyz/#gantry) to select the configuration and get the files and BOM for your build, and the [FAQ](../FAQ.md) for sourcing, print settings, and assembly notes.

Sheet metal builds require bearing-hole reaming, countersinking, and more involved assembly. Review the [printed and sheet metal comparison](../FAQ.md#should-i-choose-printed-or-sheet-metal) before choosing a build path.
