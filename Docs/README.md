# Build guides and assembly notes

Step-by-step build guides for the printed and sheet metal R1 versions are not yet available. Use the [Gantry Configurator](https://configurator.monolith3d.xyz/) to select the configuration, files, and BOM for your build, and the [FAQ](../FAQ.md) for sourcing, print settings, and assembly notes.

Sheet metal builds require bearing-hole reaming, countersinking, and more involved assembly. Review the [printed and sheet metal comparison](../FAQ.md#should-i-choose-printed-or-sheet-metal) before choosing a build path.
