# Front Motor Assembly

STEP files for the 3030 Monolith front motor assemblies.

## Files

- `3030 Front Left Motor Assembly.step`  
  Left-side front motor assembly.

- `3030 Front Motor Assemblies.step`  
  Complete front motor assembly containing both left and right sides.

- `3030 Front Right Motor Assembly.step`  
  Right-side front motor assembly.

## Notes

These files are intended for the 3030 Monolith gantry configuration and can be used for reference, modification, or integration into larger CAD assemblies.
