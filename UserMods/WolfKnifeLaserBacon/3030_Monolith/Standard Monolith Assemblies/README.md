# 3030 Monolith - Standard Monolith Assemblies

Standard Monolith gantry assemblies adapted for use with 3030 extrusions.

## Purpose

This folder contains the standard Monolith-style assembly configuration for the 3030 Monolith project.

## Notes

- Uses standard Monolith gantry geometry where possible.
- Adapted for 3030 extrusion-based builds.
- Intended to remain as close to the standard Monolith BOM and assembly layout as practical.
- Printer-specific modifications may be required depending on frame size and rail placement.

## Contents

This folder may contain:

- CAD files
- STL files
- DXF files
- Assembly files
- Variant-specific documentation
