# X/Y Joint & X-Axis Assemblies

STEP files for the 3030 Monolith X/Y joint and X-axis assemblies.

## Files

- `3030 Left XY Joint Assembly.step`  
  Left-side X/Y joint assembly.

- `3030 Right XY Joint Assembly.step`  
  Right-side X/Y joint assembly.

- `3030 X Axis Assembly.step`  
  Complete X-axis assembly.

## Notes

These files are intended for the 3030 Monolith gantry configuration.

The left and right X/Y joint assemblies are provided separately for easier reference, modification, and integration into larger CAD assemblies.

The complete X-axis assembly can be used to verify overall fitment, rail placement, and component relationships before installation.
